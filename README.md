# NEXUS Icon Pack

Pack préparé pour l'interface NEXUS.

Contenu :
- 46 éléments graphiques organisés par catégorie.
- PNG en 24 px, 48 px et 96 px.
- Fond extérieur transparent ; les cartes/cercle internes conservent le rendu premium NEXUS.
- Feuille de référence et maquette employé incluses dans `00_reference`.

Catégories :
1. Icônes principales
2. États
3. Actions
4. Outils
5. UI
6. Marque & avatars

Conseils d'intégration :
- 24 px : navigation compacte / statuts
- 48 px : cartes et boutons
- 96 px : écrans premium / raccourcis principaux
- Ne pas recolorer automatiquement les PNG : les couleurs portent une sémantique d'état.
- Pour les composants de navigation, conserver au moins 44 px de zone tactile, même si l'icône affichée fait 24 px.

Palette de référence :
- Cyan : #00D2FF
- Bleu : #0EA5E9
- Vert : #22C55E
- Orange : #F59E0B
- Rouge : #EF4444
- Violet : #6B5CF6
