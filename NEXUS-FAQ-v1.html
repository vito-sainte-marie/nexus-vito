Comprendre NEXUS

NEXUS est un système d'exploitation destiné aux commerces.

Il centralise les informations importantes de l'activité, détecte les situations qui nécessitent une attention particulière et transforme les données en actions concrètes pour les dirigeants, les managers et leurs équipes.

Non.

NEXUS ne remplace pas le logiciel de caisse. Il exploite les données issues des outils déjà utilisés par le commerce afin d'aider les responsables à mieux piloter leur activité.

NEXUS va plus loin qu'un tableau de bord.

Un tableau de bord présente des chiffres. NEXUS analyse ces informations, les hiérarchise et indique les actions prioritaires à mettre en œuvre.

Non.

NEXUS fonctionne grâce à un moteur décisionnel fondé sur des règles métier, des calculs, des seuils, des contrôles de cohérence et la Méthode NEXUS.

Les recommandations sont explicables, structurées et reposent sur les données réellement disponibles.

Non.

NEXUS accompagne le dirigeant et lui fournit des recommandations. La décision finale reste toujours humaine.

Fonctionnement

Les données peuvent être intégrées de plusieurs manières :

  • connexion avec le logiciel de caisse ;
  • API sécurisée ;
  • import de fichiers Excel ou CSV ;
  • ajout de documents PDF ;
  • saisie manuelle ;
  • photographies justificatives.

Les modes d'intégration dépendent des outils déjà utilisés par le commerce.

Oui.

Une première utilisation peut être réalisée avec des imports de fichiers ou des saisies manuelles. Une connexion automatisée permet ensuite d'améliorer la fréquence et la précision des analyses.

La fréquence dépend du mode d'intégration choisi.

Elle peut aller d'un import quotidien à une synchronisation automatique plusieurs fois par jour.

Non.

Dans son fonctionnement standard, NEXUS accède aux données en lecture seule. Il ne modifie ni les ventes, ni les produits, ni les écritures du logiciel de caisse.

Selon les modules activés, NEXUS peut notamment signaler :

  • un écart de caisse ;
  • une rupture probable ;
  • une baisse inhabituelle des ventes ;
  • une diminution des volumes ;
  • une évolution de marge ;
  • un stock incohérent ;
  • un produit à faible rotation ;
  • un inventaire à réaliser ;
  • une mission non exécutée ;
  • une anomalie opérationnelle.

Le module NEXUS Verify est conçu pour faciliter le contrôle des caisses.

Il peut rapprocher les informations provenant de différents justificatifs, comme les transactions bancaires, les rapports de coffre, les espèces, les bons clients et les inventaires.

NEXUS ne remplace pas un logiciel de stock, mais il peut analyser les niveaux de stock, les ventes, les mouvements et les inventaires afin de détecter les incohérences et de recommander des contrôles.

Oui.

NEXUS est conçu pour évoluer vers une gestion multi-sites, avec une vision par établissement et une vue consolidée pour les dirigeants.

Utilisation quotidienne

NEXUS s'adresse notamment :

  • aux dirigeants ;
  • aux gérants ;
  • aux responsables d'exploitation ;
  • aux managers ;
  • aux responsables de magasin ;
  • aux collaborateurs autorisés.

Chaque utilisateur dispose d'un accès adapté à son rôle.

Le dirigeant retrouve notamment :

  • les priorités du jour ;
  • les anomalies à contrôler ;
  • les résultats importants ;
  • les actions à déléguer ;
  • les missions en cours ;
  • les gains ou pertes identifiés ;
  • les recommandations du moteur décisionnel.

L'employé accède principalement à :

  • ses missions ;
  • ses horaires ;
  • ses actions à réaliser ;
  • ses validations ;
  • sa progression ;
  • les consignes utiles à sa journée.

Il ne voit que les informations correspondant à son rôle et à ses autorisations.

NEXUS est conçu pour être utilisé depuis un smartphone, une tablette ou un ordinateur. Les applications iOS et Android sont prévues dans la feuille de route du produit.

Les données restent la propriété du client.

NEXUS Conseil ne revendique aucun droit de propriété sur les ventes, les stocks, les collaborateurs, les documents ou les indicateurs du commerce.

Non.

NEXUS Conseil ne vend pas les données de ses clients ou de leurs collaborateurs.

Non.

NEXUS n'utilise pas les données des clients pour entraîner une intelligence artificielle.

Oui.

Chaque utilisateur dispose d'un compte individuel et de droits adaptés à son rôle. Les échanges avec la plateforme sont sécurisés et les opérations sensibles peuvent être journalisées.

Pas nécessairement.
