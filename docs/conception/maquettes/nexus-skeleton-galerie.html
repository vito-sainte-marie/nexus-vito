Retenue (26/11) : Signature + A + B, C en mouvement réduitSignature : connexion et initialisation, logo animé et étapes réelles. A : squelettes de page. B : chargements localisés (filtre, période, rafraîchissement partiel). C : rendu automatique sous « réduire les animations », sans mouvement, pour les trois familles.
A · Verre et lumièreMatière : verre teinté bleu pétrole, bord fin cyan. Lumière : reflet diagonal qui balaie chaque voile en 2,2 s. Rythme : continu, lent. Transition : le voile se dissout en flou net, les données montent de 5 px.
B · Impulsion lumineuseMatière : panneau plat, bord fin. Lumière : un filet cyan parcourt le haut de chaque carte, décalé de carte en carte. Rythme : battement 1,4 s. Transition : balayage gauche-droite qui découvre la donnée.
C · Élégance minimaleMatière : fil de bord seul, barres à peine plus claires que le fond. Lumière : aucune. Rythme : respiration 3,2 s. Transition : fondu enchaîné, sans mouvement.
