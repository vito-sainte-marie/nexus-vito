## 1. Définitions stables

| Terme | Définition |
|---|---|
| Tour dispatché | Run du workflow `claude.yml` déclenché par `repository_dispatch` dans la fenêtre |
| Commit d'un tour | Commit du rail `handoff-continuite-20260920` dont le nom d'auteur est `claude[bot]` (compte `github-actions[bot]`). Il est attribué au dernier run démarré avant lui, si ce run s'est terminé moins de 5 minutes avant. Un commit n'est attribué qu'à un seul run |
| COMPLET | Tour réussi dont les commits touchent un fichier hors `docs/handoff/`, ou ajoutent un `request-N.md` |
| PARTIEL (`REGISTRE_SEUL`) | Tour réussi dont les commits ne touchent que `docs/handoff/`, sans nouvelle demande |
| VIDE (`AUCUN_COMMIT`, `SAUTE`) | Tour réussi sans commit attribué, ou run sauté |
| ÉCHEC | Run en `failure`, `cancelled`, `startup_failure` ou `timed_out` |
| Réponse de l'arbitre | Commentaire de #28 commençant par « Réponse de l'arbitre » |
| Arrêt adressé à Frédéric | Réponse de l'arbitre dont le contrat porte `DECISION: BLOCKED` ou `OWNER_NEXT: Frédéric` |

## 4. Limites connues de la mesure

- Seuls les tours lancés par `repository_dispatch` sont comptés. Les tours lancés par un commentaire `@claude` ou par une session de Claude Code ne le sont pas.
- L'attribution d'un commit à un run repose sur l'horodatage. Elle sera remplacée par le journal des transitions (R3), qui reliera chaque commit à son run.
- Le run 38646193081 (partiel) était un essai volontaire. Il est compté tel quel.
- Un arrêt `BLOCKED` du palier de l'arbitre est compté comme adressé à Frédéric, car la matérialisation actuelle le lui envoie (matrice, ligne D6).
